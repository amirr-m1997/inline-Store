هدف:
تکمیل کامل سیستم "سفارش‌های من" برای مشتری در فروشگاه مهر اصل.

این قابلیت باید از دیتابیس کنترل شود و فقط یک صفحه نمایشی نباشد.

قبل از هر تغییر:
1- مدل‌های فعلی Cart، User، Profile، Inventory و هر مدل مرتبط با سفارش را بررسی کن.
2- اگر مدل Order که در فاز قبل ساخته شده وجود دارد از همان استفاده کن.
3- اگر وجود ندارد ابتدا معماری Order را تکمیل کن.
4- هیچ داده موجود حذف نشود.


==============================
بخش Backend و Database
==============================

1- مدل Order را کامل کن:

فیلدهای مورد نیاز:

- order_number
- customer
- status

وضعیت‌های سفارش:

pending_payment
در انتظار پرداخت

processing
در حال پردازش

confirmed
تایید شده

preparing
در حال آماده سازی

shipped
ارسال شده

delivered
تحویل داده شده

cancelled
لغو شده

returned
مرجوع شده


فیلدهای دیگر:

- subtotal
- discount_amount
- shipping_cost
- final_amount

- created_at
- updated_at

- paid_at
- shipped_at
- delivered_at


==============================

2- مدل OrderStatusHistory بساز

برای ثبت تاریخچه تغییر وضعیت:

مثال:

سفارش شماره 1001

10:00
ثبت سفارش

12:00
پرداخت موفق

14:00
در حال پردازش

روز بعد
ارسال شده


فیلدها:

- order
- status
- description
- created_at


مشتری باید بتواند تاریخچه سفارش خود را ببیند.


==============================

3- مدل Invoice بساز


برای فاکتور رسمی و شرکتی:


فیلدها:

- order

- invoice_number

- company_name

- customer_name

- national_id (در صورت وجود)

- economic_code (در صورت وجود)

- phone

- address

- items_snapshot

- subtotal

- tax

- discount

- final_amount

- created_at

- pdf_file


فاکتور نباید از اطلاعات لحظه‌ای محصول ساخته شود.

اطلاعات باید snapshot باشد.


==============================

4- ارسال فاکتور ایمیلی


امکان ارسال فاکتور به ایمیل مشتری:


API:

POST
/api/orders/{id}/send-invoice/


عملکرد:

- PDF فاکتور تولید شود.
- به ایمیل کاربر ارسال شود.
- نتیجه ارسال ثبت شود.


برای ارسال ایمیل:
از سیستم email فعلی پروژه استفاده کن.


==============================

5- API های لازم


ایجاد کن:


لیست سفارش‌های مشتری:

GET

/api/customer/orders/


فقط سفارش‌های همان User.


جزئیات سفارش:

GET

/api/customer/orders/{id}/


شامل:

- شماره سفارش
- تاریخ
- وضعیت فعلی
- تاریخچه وضعیت
- محصولات
- مبلغ
- فاکتور


ارسال فاکتور:

POST

/api/customer/orders/{id}/invoice/send/


==============================

6- امنیت


مشتری نباید بتواند:

- سفارش مشتری دیگر را ببیند.
- مبلغ سفارش را تغییر دهد.
- وضعیت سفارش را تغییر دهد.


تغییر وضعیت فقط توسط Admin انجام شود.


==============================
بخش Frontend
==============================


در پروفایل مشتری یک بخش اضافه کن:

"سفارش‌های من"


مسیر:

/fa/account/orders

نمایش کارت سفارش:


شماره سفارش

تاریخ ثبت

مبلغ کل

وضعیت فعلی

12,500,000 ریال

صفحه جزئیات سفارش:


نمایش:


- محصولات سفارش
- تعداد
- قیمت زمان خرید
- تخفیف
- مبلغ نهایی


نمایش Timeline وضعیت:

پردازش

ارسال
 |
تحویل


مرحله فعلی با رنگ مشخص شود.
