Implement Phase 9.14C — Mobile Category Navigation + Catalog Overflow Repair.

IMPORTANT:

This is a mobile-first screenshot/video driven repair.

Do not add backend features.
Do not change category APIs.
Do not change search semantics.
Do not change catalog-query contracts.

Goal:
Fix the mobile navigation/category experience and all catalog control overflow
issues visible at ~388px width.

==================================================
1. MOBILE MENU INFORMATION ARCHITECTURE
==================================================

The current mobile menu is wrong.

Right now:
- primary navigation is visible
- then the category tree is appended below it
- category expansion creates a long dark wall
- both systems remain visible together

Replace this with TWO DISTINCT MOBILE MENU MODES:

MODE A — MAIN MENU

Show:

تماس با ما

The category entry should be visually prominent and appear BEFORE the regular
navigation links.

Do not render the category tree in this mode.

==================================================

==================================================

Hide the normal primary navigation list.

Show only:

Category rows

below it.

==================================================
4. CATEGORY ROW DESIGN
==================================================

Make category rows compact.

Each row should contain:

category title
optional product count
one chevron/arrow

Avoid:
- giant dark full-width blocks
- arrows on separate rows
- excessive vertical padding
- repeated gold borders

Use restrained separators.

==================================================

The menu should fit naturally within viewport height.

Use:

scrollable menu content

Do not make the whole page body extremely tall.

Prevent double scrolling.

Lock background scroll while drawer/menu is open using existing accessible
Drawer behavior.

==================================================

- search input
- technical search
- sort select
- product code/SKU inputs
- range inputs
- facet labels
- active filter chips

Find exact overflow source.

Fix layout structurally.

Use where appropriate:

text-overflow
