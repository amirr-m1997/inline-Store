# پنل مدیریت مهراصل — Django 5.2 + django-unfold

پنل عملیاتی فروش B2B برای «مهر اصل» (تولیدکنندهٔ چیلر، هواساز، فن‌کویل، برج خنک‌کننده، لوله و اتصالات مسی).
این مخزن، پیاده‌سازی واقعی و اجراشدنی همان طرح بصری تأییدشده است: راست‌به‌چپ، فونت وزیرمتن، ارقام فارسی،
پالت سرمه‌ای/فیروزه‌ای (`#0e7490` / `#0891b2`) و اجزای نموداری SVG بدون وابستگی به سرویس بیرونی.

---

## ۱) راه‌اندازی سریع

```bash
pip install -r requirements.txt

python manage.py migrate            # ساخت پایگاه‌داده (SQLite)
python manage.py seed_demo          # داده‌ی نمونه‌ی واقع‌نما (۱۱ گام، ۱۴ مشتری، ۹۶ سفارش)
python manage.py check_alerts       # تولید اعلان‌های هشدار (موجودی، SLA، چک، اعتبار…)
python manage.py compile_po         # کامپایل ترجمه‌ی فارسی رابط (بدون نیاز به msgfmt)

python manage.py runserver 0.0.0.0:8000
```

برای نمایش دمو بدون مرحله‌ی ورود:

```bash
PANEL_DEMO_AUTOLOGIN=1 python manage.py runserver 0.0.0.0:8000
```

**کاربران نمونه** (همه با گذرواژه‌ی `Mehr@1405`):

| کاربر | نقش |
|---|---|
| `admin` | مدیر سیستم (دسترسی کامل) |
| `manager` | مدیر فروش (تأیید سفارش‌ها) |
| `sales1` / `sales2` / `sales3` | کارشناس فروش |
| `finance1` | مدیر مالی (فاکتور، چک، سامانه مؤدیان) |
| `store1` | انبار |
| `content1` | تولید محتوا (کاتالوگ) |
| `tech1` | کارشناس فنی |
| `cu0-admin` / `cu0-buyer` / `cu0-approver` | کاربران پنل مشتری (نمونه) |

## ۲) تست خودکار پنل

```bash
python manage.py panel_check        # ۳۷ تست: پوشش مدل‌ها، فرم‌ها، فیلترها، مسیرها، اکسل، سفارش سریع، اعلان، لاگ
python manage.py panel_check --keep # همان تست‌ها بدون rollback (برای بررسی دستی)
python manage.py test               # تست‌های واحد Django (در صورت افزودن)
```

`panel_check` همه‌چیز را در یک تراکنش اجرا و در پایان rollback می‌کند؛ بنابراین پایگاه‌دادهٔ دمو دست‌نخورده می‌ماند.

تست‌های UX/UI (بازبینی ۱۴۰۵/۰۷/۱۵):

```bash
python3 scripts/ux_audit.py            # سنجش UX/UI ۳۴ چک‌لیست + ۵ صفحه‌ی سفارشی (خروجی --json هم دارد)
python3 scripts/export_model_docs.py   # تولید docs/model-names-and-help.md از نام‌ها و توضیح مدل‌ها
node scripts/check_panel_js.js         # ۲۱ بررسی الگوریتم تاریخ شمسی/میلادی در static/js/panel.js
python3 scripts/dump_admin_fixtures.py /tmp/fx        # ذخیره‌ی HTML واقعی صفحه‌های پنل
NODE_PATH=/tmp/jsd/node_modules node scripts/check_panel_dom.js /tmp/fx   # ۲۷ بررسی DOM روی HTML واقعی
```

## ۴) مدل‌ها روی پنل

هر ۳۲ مدل دامنه روی پنل ثبت شده‌اند (`panel_check` این را می‌سنجد). جدول کامل مدل → صفحه → فیلتر/جست‌وجو/اکشن‌ها
در `docs/panel-implementation-and-tests.md` آمده است.

## ۶) دادهٔ نمونه

`seed_demo` این‌ها را می‌سازد: ۳۶ محصول HVAC با مشخصات فنی، ۵ سبد قیمت با پله‌های حجمی، ۳ انبار با موجودی
(شامل اقلام کم‌موجود)، ۱۴ مشتری سازمانی با کاربران و نشانی، ۳۴ استعلام با SLA (بخشی سپری‌شده، بخشی نزدیک مهلت)،
۹۶ سفارش در ۶ ماه (۳۰ روز آخر: هر روز حداقل یک سفارش تا نمودار روند پیوسته باشد)، فاکتور/پرداخت/چک،
قواعد تأیید و ~۱٫۵ هزار رکورد لاگ حسابرسی.

## ۶٫۵) ساخت پیش‌نمایش تک‌فایلی (آفلاین) از داده‌های پایگاه‌داده

```bash
python3 scripts/build_static_preview.py            # → ../mehrasl-panel-db-preview-v2.html
python3 scripts/build_static_preview.py --out out.html
```

این اسکریپت با همان قالب‌ها و همان پایگاه‌داده، یک فایل HTML مستقل می‌سازد که ۱۹ زبانه دارد:
چهار صفحهٔ سفارشی پنل (داشبورد، گزارش‌ها، سفارش سریع، اعلان‌ها)، هشت چک‌لیست واقعی مدل‌ها
(محصولات، استعلام‌ها، سفارش‌ها، فاکتورها، حساب‌های سازمانی، موجودی، چک‌ها، سبدهای قیمت، پرداخت‌ها، درخواست‌های خرید، اعلان‌ها، مراحل تأیید، کاربران مشتری، لاگ حسابرسی)
و زبانهٔ «منبع داده» که تعداد رکورد هر مدل و مشخصات فایل پایگاه‌داده را نشان می‌دهد.
CSS، فونت وزیرمتن، آیکون‌ها و نمودارهای SVG همه درون فایل قرار می‌گیرند (بدون CDN و بدون سرور).

## ۷) نکات فنی که در پیاده‌سازی رعایت شده

- **حلقهٔ وابستگی مهاجرت‌ها**: `Order.quote` حذف و به `Quote.order` (سرِ رابطه) تبدیل شد؛ `inventory.StockMove.order`
  در یک مهاجرت دوم اضافه می‌شود تا چرخهٔ quotes↔orders↔inventory رخ ندهد.
- **استاتیک مطلق**: `STATIC_URL = "/static/"` و `STYLES` با `static()` — بدون این کار CSS در صفحه‌های تودرتو بارگذاری نمی‌شد.
- **فونت محلی**: وزیرمتن در `static/fonts/` قرار دارد (بدون CDN؛ مناسب اجرای داخلی/آفلاین).
- **ترجمهٔ فارسی**: `django-unfold` فایل ترجمه ندارد؛ `locale/fa/LC_MESSAGES/django.po` + دستور `compile_po`
  (پیاده‌سازی دستی فرمت MO) رابط را کامل فارسی می‌کند.
- **ارقام فارسی** با فیلترهای `fa_digits`/`num_fa`/`money_fa` و `font-variant-numeric: tabular-nums` برای مبالغ.
- **حسابرسی خودکار** روی ۱۶ مدل حساس با ثبت قبل/بعد تغییرات (`core.audit.track_all`).
